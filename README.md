# ServerSeed

Ubuntu Server 24.04 LTS向けのRust製CLI。サーバ構成とマイニング構成の導入・更新・検証・復旧を管理します。

導入・保守は、物理PCではISOを用意した外部媒体、VPS・クラウドでは物理マスターからのSSHを入口とします。方式の全体像は[製品仕様](docs/core/product-scope.md)を参照してください。

開発状況は[ロードマップ](docs/ROADMAP.md)を参照してください。
