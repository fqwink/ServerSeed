# マスター管理とSSH自動処理

[文書一覧](../DOCUMENT_INDEX.md)

## 責務

マスターは、Cloud対象の選択、接続、計画の確定、処理の開始と結果照合を担当する。必須台数・構築元・通常運用・対象別の実行入口は[運用条件](../POLICIES.md#実行入口と通常運用)を参照する。

マスター管理は共通基盤の管理上の役割であり、`server`・`mining`に加える第三の構成ではない。対象OSへの構成適用は各構成、状態・排他・実行記録は[共通基盤](common-platform.md)、SSH先の導入処理は[Cloud仕様](cloud.md)が担当する。マスター自身の管理情報と、管理先の情報を分離する。

## 初期構築

1. [外部媒体の手順](usb.md#セットアップ)で物理PCの内蔵OSと選択した構成を構築する。
2. 利用者が当該PCをマスターとして使用することを選択し、マスター用の初期設定を行う。構成値にマスターの役割を代入せず、管理設定は[設定責務](configuration.md#マスターと対象の設定)へ対応付ける。
3. [内蔵OSの起動確認](firmware.md#内蔵osの起動確認)を行い、マスター機能を内蔵OSから起動して、Cloud管理の準備状態を確認する。

マスター機能の初期設定入力、選択画面とCLIは[未確定契約](#未確定契約)の対象とする。

## 自動処理の流れ

1. マスター側で対象を識別し、インストール、セットアップ、更新、バックアップまたは復旧の操作を利用者が選択する。
2. SSH接続先の識別と認証を確認して接続し、[実行環境と対象OS](cloud.md#実行環境と対象os)を分けて検査する。接続・検査だけで変更の実行を開始した扱いにしない。
3. 対象状態に応じて、構成、対象ディスク、必要な保存先と入力を利用者に提示する。選択・自動化の許可条件は[必須選択と自動実行](../POLICIES.md#必須選択と自動実行)に従う。
4. 対象の識別情報、変更内容、固定した成果物、バックアップ、管理経路、必要権限、再起動・再接続と復旧可否を計画に対応付け、必要な確認をマスター側で受ける。対象側の対話入力を放置して自動処理を待たせる方式にはしない。
5. 確定した計画を対象側の共通処理へ渡し、[実行側と対象側](lifecycle.md#実行側と対象側)の責務に従って直列に適用する。対象OSへの導入・更新・バックアップの手順は各正本を使用する。
6. 必要な再起動後に同じ対象へ再接続し、対象側の状態・実行記録と検証結果を照合して、成功・失敗・未確認および残作業をマスターに表示する。

対象機器・計画・操作IDの対応、選択結果の受け渡し、記録の保存形式は下表で未確定として管理する。既存の[操作状態](common-platform.md#操作状態)へ未定義の遠隔制御フィールドを追加したものと扱わない。

## 中断と結果照合

SSH切断、マスター停止、対象再起動で結果を受け取れなかった場合は、成功・未実行のどちらとも推測しない。対象側の操作状態・ロック・実配置と固定した計画を再取得して照合し、確認できるまで同じ変更の再投入や別の変更を開始しない。実行中・中断の扱いは[前回処理状態](common-platform.md#前回処理状態)を参照する。

再接続先のホスト鍵や機器識別情報が変わった場合は、[管理経路の保護](../POLICIES.md#cloudの管理経路)に従った照合をOS再導入の計画に含める。マスターと対象の記録に不一致・欠損があれば、その範囲を未確認として提示する。

## 未確定契約

次の具体的な入力・形式・判定値は未確定であり、[仕様充足の判定](../POLICIES.md#実装着手と仕様充足の判定)を満たすまで依存する機能は実装しない。

| 対象 | 確定する契約と担当正本 |
|---|---|
| マスター初期設定・対象登録 | 役割の有効化、対象IDと接続先の対応、選択済み情報の形式・保存・変更・解除。[共通設定](configuration.md#マスターと対象の設定) |
| 利用者インターフェース | [自動化入口のCLI契約](cli.md#自動化入口のcli契約)の確定と本書の処理フローへの対応付け |
| SSH | 使用する外部実行物・固定版、ホスト鍵の信頼確立、認証、秘密情報の非平文管理、権限昇格、接続・実行の時間制限、転送と引用の安全性。本書の接続・制御責務と[外部依存台帳](../DEPENDENCY_EXCEPTIONS.md) |
| 実行制御 | 計画と対象・操作IDの結合、要求の配送と重複防止、対象側排他の確認、記録の照合、キャンセル・切断・再起動時の継続可否。本書の処理フローと[実行側と対象側](lifecycle.md#実行側と対象側) |
| 再接続・復旧 | 本書の中断処理と、[Cloudの再接続契約](cloud.md#未確定契約)・[マスター管理情報の復元](backups.md#未確定契約)の対応付け |

本書のフロー定義を、これらの契約が完成したことや実機で動作確認済みであることの根拠にしない。
