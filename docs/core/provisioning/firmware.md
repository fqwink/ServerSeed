# BIOS・UEFIの検査と設定

[文書一覧](../../DOCUMENT_INDEX.md)

## BIOSおよびUEFI

### ISOの起動互換性

初期のISO検証対象は次のとおりとする。

| アーキテクチャ | 起動方式 |
|---|---|
| `amd64` | UEFI、Legacy BIOS |
| `arm64` | UEFI |

媒体マニフェストの`boot_modes`は、成功した方式を`uefi`または`bios`で記録する。要求起動方式に対する公開条件は[公開前の検証](../../POLICIES.md#公開前の検証)を参照する。機種固有のファームウェアやブート方式を必要とするARM機器は、UEFIサーバ向けISOの成功から対応を推測しない。

`secure_boot`は`verified`、`not_verified`、`not_supported`とする。OpenPGPによる配布物の真正性確認とUEFI Secure Bootは別の検証である。`verified`は有効状態でのブートチェーン・カーネル・本体起動を検証した対象に限り、対象ファームウェアと試験結果を配布メタデータへ付ける。無効状態での試験だけで対応を保証しない。

有効状態を確認できない場合の案内と設定変更の制約は[ファームウェア操作](../../POLICIES.md#ファームウェア操作)を参照する。

### 操作の参照

検査・自動化の基本的な扱いは[ファームウェア自動化](../../PRINCIPLES.md#ファームウェア自動化)を参照する。

### 自動化対象

対応するUEFI環境では次を自動化できる。

- UbuntuのUEFI起動項目作成
- ブートローダー登録
- 起動順序の検査および変更
- 次回起動先の指定
- 不要な起動項目の検査

### 手動設定の可能性がある項目

次は機種依存のため、初回に手動設定が必要となる場合がある。

- UEFIモード
- USB Boot
- USBを内蔵SSDより優先する起動順序
- Secure Boot
- 停電復旧後の自動電源ON
- 仮想化機能
- Wake on LAN
- TPM
- ストレージモード

推奨起動順は[ファームウェア操作](../../POLICIES.md#ファームウェア操作)を参照する。

変更を禁止する項目も[ファームウェア操作](../../POLICIES.md#ファームウェア操作)を参照する。

### 機種別の自動設定と復電確認

機種と利用可能な公式操作手段を検出し、対応する場合は復電時の自動電源投入、Wake on LANなど選択済みポリシーに必要な項目を自動設定する。現在値の記録、変更、読み戻し確認、再起動要否の記録を行う。メーカー・機種別処理はplatform配下で共通制御から分離する。操作可否は[ファームウェア操作](../../POLICIES.md#ファームウェア操作)に従う。

項目別に成功、失敗、非対応、未確認を記録する。設定値の確認と実際の復電起動テストは区別し、実機テスト未実施なら「設定済み・復帰動作未確認」とする。OS全体の停止や完全電源断からの復帰は、対応ハードウェアと設定が確認できた範囲のみ提供し、すべての機種での復帰を保証しない。
