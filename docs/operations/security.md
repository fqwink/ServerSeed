### 秘密情報の分類

秘密情報として扱う値は次を含む。

- SSH秘密鍵
- APIトークン
- パスワード
- バックアップ暗号鍵
- Tailscaleなどの認証トークン
- Cookie、セッション、Bearerトークン

保存・入力・マスクの条件は[秘密情報](../POLICIES.md#秘密情報)を参照する。
