### バックアップ状態

バックアップ状態はServerSeedが直接作成したもの、またはアプリ定義で指定された確認コマンドの結果から判定する。

バックアップ成功状態は少なくとも次を含める。

```json
{
  "schema_version": 1,
  "app": "example",
  "last_success_at": "RFC3339",
  "method": "command",
  "location": "string",
  "verified": true
}
```

更新前提としての判定は[バックアップの成功条件](../POLICIES.md#バックアップの成功条件)に従う。
